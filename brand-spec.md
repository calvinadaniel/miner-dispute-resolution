## Typography (live site lift)

- **Display / headings:** Kanit (as on live meet page)
- **Body:** Noto Sans
- Redesign keeps these families for brand continuity; elevates scale, tracking, and hierarchy rather than inventing a new type system.

## Voice / temperament

Professional, impartial, calm, efficient. Avoid flashy tech-SaaS aesthetics. Visual motif: **balance / scales** — symmetry, measured spacing, gold hairline rules.

## Forbidden (anti-slop)

- Purple gradients, neon glows, emoji icons
- Generic Inter/Roboto as display
- Card-grid hero; left-border accent cards as default pattern
- CSS silhouettes instead of real logos / headshot
